# 1. 프로젝트 개요
- 1.1. 내가 spring 공부를 하면서 여러기술들을 사용해보고 이를 설명하는 페이지와 기능들을 사용할수있는 페이지를 만들면서
기술 블로그를 만드는 것이 목표

# 2. 기술스펙
## 2.1 전체적인 구조
- 프론트엔드의 경우 리액트로 구성할것고, 백엔드는 spring 으로 만들 예정이다.
- 백엔드의경우 msa 방식으로 만들것인데, 프론트의 경우 어떻게 만들어야할지 모르겠으니 msa 방식의 프로젝트와 리액트 프로젝트서로 호환할수있게
프로젝트를 구성해줄 것
## 2.2 프론트 엔드
- 리액트를 사용하여 화면을 만들것

## 2.3 백엔드
- spring boot 의 msa 방식으로 프로젝트를 구성할 예정

# 3. 서버
- 서버의 경우 Render(https://dashboard.render.com/) 라는 곳에 github를 이용하여 빌드할 예정이다.

# 4. 사양
- 프론트 엔드
  - 리액트를 사용하는데 안정화된 최신버전을 사용할 것
- 백앤드
  - spring boot를 사용하는데 spring 6버전에 해당되는 버전을 사용할 것

# 5. 규칙
- 주석은 최대한 자세히 한글로
- 코딩 스타일은 Google Java Style, Functional React 로 기록해줘
